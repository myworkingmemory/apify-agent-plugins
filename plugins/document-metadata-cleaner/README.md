# Apify Document Cleaner

Inspect ordinary PDF and DOCX metadata and create a separately verified cleaned copy. Inspect before cleaning and obtain any required approval for content changes. This is not redaction or guaranteed anonymization.

MCP endpoint:

```text
https://mcp.apify.com?tools=myworkingmemory/document-metadata-cleaner,fetch-actor-details,call-actor&telemetry-enabled=false
```

Authenticate using your own Apify account with OAuth; metered Actor runs are charged to your account.

Example: Inspect the metadata in my selected ordinary PDF before making any changes.

See the repository README for Codex, workspace and API distribution instructions. This package is not an approved OpenAI public-directory listing.
