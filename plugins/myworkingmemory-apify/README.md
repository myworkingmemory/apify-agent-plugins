# Myworkingmemory Apify Tools

Use Myworkingmemory LLC’s metered Apify Actors for public Shopify catalogs, ordinary document metadata cleanup, email verification and curated software discovery. Each customer connects their own Apify account; pricing and third-party supplier costs apply.

MCP endpoint:

```text
https://mcp.apify.com?tools=myworkingmemory/shopify-store-extractor,myworkingmemory/document-metadata-cleaner,myworkingmemory/email-verifier-bulk,myworkingmemory/software-library-search,fetch-actor-details,call-actor&telemetry-enabled=false
```

Authenticate using your own Apify account with OAuth; metered Actor runs are charged to your account.

Example: Show the four available tools and their current prices before running anything.

See the repository README for Codex, workspace and API distribution instructions. This package is not an approved OpenAI public-directory listing.
