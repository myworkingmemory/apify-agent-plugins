# Apify Email Verification

Verify email lists or Apify datasets with the customer’s MillionVerifier key or the limited keyless pilot when available. Supplier credits are separate for BYOK; duplicates, unknowns, catch-alls and errors have no result fee. Never promise deliverability.

MCP endpoint:

```text
https://mcp.apify.com?tools=myworkingmemory/email-verifier-bulk,fetch-actor-details,call-actor&telemetry-enabled=false
```

Authenticate using your own Apify account with OAuth; metered Actor runs are charged to your account.

Example: Check the available modes and pricing before verifying my email list.

See the repository README for Codex, workspace and API distribution instructions. This package is not an approved OpenAI public-directory listing.
