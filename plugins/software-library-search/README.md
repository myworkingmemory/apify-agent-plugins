# Curated Software Finds

Search a curated catalog of GitHub tools and Hugging Face models. Return original source links, available setup notes and review dates. Results are a dated curated collection, not an exhaustive live search; the Actor does not install or run the listed tools.

MCP endpoint:

```text
https://mcp.apify.com?tools=myworkingmemory/software-library-search,fetch-actor-details,call-actor&telemetry-enabled=false
```

Authenticate using your own Apify account with OAuth; metered Actor runs are charged to your account.

Example: Find curated PDF tools and show their source links and review dates, within $0.01.

See the repository README for Codex, workspace and API distribution instructions. This package is not an approved OpenAI public-directory listing.
